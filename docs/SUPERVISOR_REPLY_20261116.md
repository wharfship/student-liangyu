# 给导师的阶段答复草稿

老师，我已围绕硬化肾小球整理现有结果。目前能确认部分漏检和明显范围错误值得继续处理，但还没有找到稳定优于SegFormer的专用补救方案，暂不能说已完成“专用方案确实有改善空间”的验证。

医院现有40个已标注硬化目标中，SegFormer有37个达到IoU≥0.5匹配，3个完全遗漏；包含遗漏的平均目标Dice为0.8421。已检出37个的平均Dice约0.9104，说明完全遗漏与已检出目标的轮廓问题需要分开分析。硬化边界本身也有争议，下一步先区分真实失败、原图问题和标注不确定，保留原评分，不用微小Dice变化直接证明修复有效。

我们实测了SAMRefiner、RITM及MESCnn不同输入配方，均未带来硬化整体净收益；SegNeXt曾补回1例，但丢失2例原匹配，65个独有候选仅1个达到GT匹配。MESCnn、RITM和SegNeXt补漏方向已停止推进。Skinet在本机已完成单图运行，但完整输入协议和配对精度尚未验收，仍作为禁用候选。其他核分析、检索和质控工具可提供辅助证据，尚不能当作硬化分割或专业验收工具。

接下来先选可明确评价的错误，验证具体动作能否多例改善，同时记录普通球、邻球误伤和新增FP；没有有效动作时先调整专用方法，暂不扩大Agent实验。动作成立后，再在相同动作池与预算下比较SegFormer、专用方案、强固定规则和动态Agent。主动观察按“当前疑问→原始局部/周边上下文/修改差异→接受或保留”设计，并用固定观察作对照，检验最终分割收益和额外成本。
