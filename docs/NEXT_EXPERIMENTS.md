## 1. 先把错误与不确定性分开

当前内部 P0 已扩为医院551个原GT对象及140个在IoU≥0.5一对一匹配评价中未匹配的预测，原40硬化仍可筛选。551是全部对象而非551个硬化球；140不等于病理确认的误检。内部图库及人工备注不导出。

完全遗漏优先确认位置是否有球、是否硬化、图像是否可读、是否标注错位；低 Dice 再区分真实范围错误与轮廓争议。用户已指出硬化边界难辨，不能把与GT的每一处差异都写成模型错误。未知保留未知，不代填病理结论。不得无授权改GT。

存在性评价和边界评价分开。双人或病理复核可确认存在的对象进入存在性评价；边界共识部分与有争议部分另记。沿用原GT的结果保留，另行报告经确认子集及边界容差敏感性，事后不能只挑有利边界规则。若无法达成轮廓共识，主结论限于漏检、误检和明显范围错误，不用千分位 Dice 差异证明修复有效。

## 2. 专用动作的选择与淘汰

- 不再重跑 MESCnn、RITM、SegNeXt 补漏；这些方向已按用户决定停用。
- Skinet 仅保留为未验收候选。先核作者皮质裁切、1024工作窗、倍率/尺度、预处理和权重许可。单图能输出掩膜不构成部署验收。协议仍无法对齐，或对齐后持续出现大片组织误判，则停止该候选，不直接扩展80目标。
- C004 网格复查及 C003 跨层读取分别是局部分割动作和输入恢复构件。先保留现有后续反例，不以单例成功开放自动替换。跨层输入恢复需另行统一入口接入与同坐标分割验收。
- 其他文献候选先过代码、完整任务权重、训练域/尺度和许可的资产检查；论文名称含硬化不等于本队列有效。现有资产不足时，后续可设计专用模型适配，但需新的患者独立划分、训练预算和运行记录，当前不自动启动训练。

进入调度实验前，动作必须在明确的失败类型上多例产生收益，同时记录全部候选、普通球误伤、FP与失败成本。当前尚未满足此条件。动作失败时，整理负结果后换假设，不能用Agent包装掩盖动作无效。

## 3. 主动观察能回答什么

Agent 先明确疑问，再按需请求原始局部、周边上下文、修改前后差异；必要时查看质量提示、核测量或相似区域。图像发送用JPEG副本；原图、掩膜和GT不改格式、不覆盖。

已有上下文质控补足两次窄视野漏报的事后线索，但没有动态策略成绩。新核/表征/QC工具不能直接充当存在性裁判，不能把低核数解释为硬化、QC未提示解释为合格，或检索近邻当病理诊断。

在同一个已有效动作池上比较固定局部观察、固定多视图、按疑问动态观察，并加上不使用VLM的强数值规则。请求视图、传输像素、模型调用、输入/输出Token及墙时分别计账；固定多视图和动态观察共享预算上限，另报告实际成本。Agent只能基于原图、当前预测和工具反馈决定keep/accept/reobserve/manual_review/stop，不读GT或EVAL_ONLY文件。manual_review保留原结果并交人工复核，不自动接受提案；复核工作量单独计入。
