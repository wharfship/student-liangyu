# 候选动作构件

这些构件来自原工作区，不是新的推理入口或工具主表，尚未开放自动修改分割。推理仍须通过 `python -m glomerulus_tools` 和原 catalog；本目录代码可供接入前审查。

- `shifted_grid.py`：在原全图工作格上规划有限平移窗口、调用预测函数、融合局部概率。C004已有单例恢复及冻结概率回放；后续6候选中有2例明显恶化并出现目标消失，不能统一平移或自动采用。
- `pyramid_read.py`：按显式金字塔层和原生/工作格坐标只读恢复输入。C003正常低层可恢复组织，尚未执行替代输入的分割；不自动判坏层、不自动选层，不覆盖源图、缓存或旧预测。

输入输出和适用限制见代码 docstring。完整内部图册、诊断NPZ及病例级运行收据未外发；本库[结果摘要](../../docs/RESULTS.md)保留结论和边界，来源SHA在 `provenance/`，不能仅凭本构件声称复算了实例精度。
